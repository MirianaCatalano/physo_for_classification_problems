# PhySO for Classification Problems

This repository contains the code and configuration files used to investigate the application of Physical Symbolic Optimization (PhySO) to classification problems.

The project evaluates symbolic expressions generated by PhySO on synthetic datasets derived from Feynman equations, considering both regression and classification settings.

## Project Structure

```
.
├── configs/                  # Configuration files for the different pipeline steps
├── scripts/                  # Main scripts implementing the analysis pipeline
├── utils/                    # Utility and input-validation functions

├── tests/                    # Generated datasets, splits, and results (not tracked by Git)
├── requirements.txt          # Python dependencies
├── README.md                 # Project documentation
├── .gitignore
└── LICENSE
```

## Installation

### Requirements

The project was developed and tested with Python 3.9.

The required Python packages and their versions are listed in `requirements.txt`.

### Setup

Clone the repository and move into the project directory:

git clone https://github.com/MirianaCatalano/physo_for_classification_problems.git
cd physo_for_classification_problems

### Create and activate a virtual environment

python3.9 -m venv venv
source venv/bin/activate

### Install the required dependencies

python -m pip install -r requirements.txt

## PhySO Modification

The experiments were performed using PhySO version 1.1.11 with a minor modification to the source code.

In `physo/physym/dimensional_analysis.py`, exact floating-point comparisons used for dimensional consistency checks were replaced with `np.allclose()` using an absolute tolerance of `1e-15`. This modification avoids numerical precision issues when comparing physical unit vectors.

The modified file is provided in:
physo_modifications/dimensional_analysis.py

## Pipeline

The analysis is organized into the following sequential pipeline:

1. **Dataset generation**
   Synthetic datasets are generated from selected Feynman equations, with configurable sample size, noise level, and random seed.

2. **Label binarization**
   Continuous targets are converted into binary classification labels using configurable quantile thresholds.

3. **Dataset splitting**
   The generated datasets are split into folds for regression and classification experiments, separately considering clean and noisy data.

4. **PhySO symbolic regression**
   PhySO is run on each fold to discover symbolic expressions, using task-specific configurations for regression and classification.

5. **Expression evaluation**
   The best expression found by PhySO and the expressions belonging to the Pareto front are evaluated on training and test data. Pareto-front expressions are also used as symbolic features for conventional machine-learning models.

6. **Results summary**
   Results from all folds and experimental configurations are collected and summarized using aggregate statistics.

7. **Visualization**
   Expression frequencies and classification performance across noise levels and class-imbalance conditions are visualized using histograms and heatmaps.

The corresponding scripts are:

```
01_generate_dataset.py
02_binarize_label.py
03_split_dataset.py
04_run_physo.py
05A_evaluate_best_expression.py
05B_evaluate_pareto_front.py
06_results_summary.py
07A_plot_histograms.py
07B_plot_heatmaps.py
```

For a detailed description of each pipeline step, see the [Pipeline Guide](docs/pipeline.md).


## Configuration

The parameters used by the different steps of the pipeline are defined in the configuration files stored in the `configs/` directory.

A detailed description of all configuration parameters is available in the [Configuration Guide](docs/configuration.md).


## Usage

The pipeline should be executed sequentially, starting from dataset generation and proceeding through dataset preprocessing, symbolic regression, evaluation, and results analysis.

Each script reads its parameters from the corresponding configuration file in the `configs/` directory.


## Results

The results generated by the pipeline are stored under the `tests/` directory.

For each equation and experiment, the pipeline stores the generated datasets, dataset splits, PhySO results, and subsequent evaluation results.

The experiments distinguish between:

- **Regression** and **classification** tasks.
- **Clean** and **noisy** datasets.
- Different classification thresholds (`thr_50`, `thr_75`, and `thr_90`).

The `tests/` directory is excluded from version control through `.gitignore`, since it contains generated data and experimental results.

## Reproducibility

To facilitate reproducibility, the versions of the main Python dependencies used in the experiments are fixed in `requirements.txt`.

The experiments use a fixed random seed, specified in the configuration files, to ensure reproducible dataset generation and data splitting.

The PhySO version used in the experiments is `1.1.11`. A minor modification to PhySO's dimensional analysis module is required for the experiments; the modified source file is provided in `physo_modifications/`.

The complete experimental pipeline can be reproduced by running the scripts in the order described in the [Pipeline](#pipeline) section.
